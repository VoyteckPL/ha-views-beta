# HA Views Beta

> Test channel for **HA Views**. It can change often and may contain unfinished features.

Create visual Home Assistant dashboards on an image or a solid colour background. Add entity markers as configurable **Badge** and **Gauge** cards, then arrange them independently in each view.

## Install the beta

1. In Home Assistant open **Settings → Add-ons → Add-on Store**.
2. Open the menu (⋮) → **Repositories**.
3. Add:
   `https://github.com/VoyteckPL/ha-views-beta`
4. Refresh the store and install **HA Views Beta**.

The stable channel is available separately at:
`https://github.com/VoyteckPL/ha-views`

## Update flow

- New beta builds are published here for testing.
- The stable repository is updated only after a beta is confirmed.

# HA Views Beta — Polski

> Kanał testowy dodatku **HA Views**. Może zmieniać się często i zawierać funkcje w trakcie prac.

Twórz wizualne pulpity Home Assistant na obrazie lub jednolitym kolorze tła. Dodawaj encje jako konfigurowalne markery **Badge** i **Gauge**, a potem niezależnie układaj je na wielu widokach.

## Instalacja beta

1. W Home Assistant otwórz **Ustawienia → Dodatki → Sklep dodatków**.
2. Menu (⋮) → **Repozytoria**.
3. Dodaj:
   `https://github.com/VoyteckPL/ha-views-beta`
4. Odśwież sklep i zainstaluj **HA Views Beta**.

Stabilna wersja jest dostępna osobno:
`https://github.com/VoyteckPL/ha-views`

## Zasada aktualizacji

- Tutaj trafiają kolejne wersje beta do testów.
- Repozytorium stable aktualizujemy wyłącznie po potwierdzeniu sprawdzonej bety.
